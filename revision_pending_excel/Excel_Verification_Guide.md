## 1. 保留原始来源和随机化记录

在 Mac 的 Microsoft Excel 中打开**原来已随机化的同一份 XLSM**，另存工作副本为 XLSM。保留完整的原始数据工作表和 `Dataset` 工作表，不重新下载或随机化，不编辑 `Dataset!B6`。记录原始文件名、数据工作表名、数据首尾行、20 个变量的列位置及 B6 完整文字。

原截图显示随机化时间为 `2026-10-07 06:20:30`，没有时区信息；模板里的这条记录仅来自截图，不等于保存了原始 B6 单元格。最终证据工作簿必须实际保留原单元格。

在 Excel 设置中保持 **Set precision as displayed / 以显示精度为准**关闭。不要另存 CSV 来进行本轮分析；更改显示的小数位不会改变存储精度，但启用“以显示精度为准”会改变数据。不要用 ROUND 后的值检查众数。

## 2. 留下清洗公式、原始行号和审计记录

复制原始数据工作表作为 `Working`，原始工作表保持完整。下面示例假定列位置与旧 CSV 一致：A=Brand、G=Fuel_Type、L=Kms_Driven、S=Registration_Age、T=Car_Price，标题在第 1 行。**先对照原始 XLSM 验证列位置与标题行，再修改公式引用。** 在辅助列中操作，不覆盖 A:T：

| 辅助字段 | 第 2 行示例公式或操作 |
| --- | --- |
| Original_Row | `=ROW()`；下填后粘贴为数值固定，保留对应的原始工作表名称；若原始数据不是从第 2 行开始，应使用原始工作表的实际行号 |
| Brand_Clean | `=TRIM(A2)`；记录 TRIM 也会压缩重复内部空格，逐个核对前后标签 |
| Segment | `=IF(OR(V2="",LOWER(V2)="unknown"),"Unclassified",IF(OR(V2="Audi",V2="BMW",V2="Mercedes"),"Luxury","Non-luxury"))`，假定 V 为 Brand_Clean；所有其他标签先核对确为有效品牌 |
| Fuel_Clean | 在辅助列用 `LOWER(TRIM(G2))`，再用明确的标签对照表归一；对照表保留 hybridd→Hybrid、electrik→Electric；未识别的新标签保留待查，不能猜测 |
| Brand_Changed | `=NOT(EXACT(A2,V2))` |
| High_Usage | `=IF(ISNUMBER(L2),L2>1000000,FALSE)` |
| Invalid_Usage | `=IF(ISNUMBER(L2),L2<0,TRUE)`；与高里程筛选分开记录 |

对空白值、非数值、Unknown、负值、辅助机械变量的零值分别审核。不要把零直接当作缺失值。缺失价格、年龄或里程的记录如影响某项统计，说明该统计的有效 n；相关系数须使用双方均有效的相同行。

在临时副本中用“删除重复项”**只选择原来的全部 20 个变量**检查重复数；不要包含 Original_Row、随机数或其他辅助列，否则会掩盖重复。分别在标签清洗前后审核；原始工作表和待查记录保留。记录“发现数量”与“实际删除数量”，不能直接套用旧 CSV 的零重复结果。

`Audit_log` 每条规则记录：原始问题、Excel 公式/菜单操作、受影响数量、保留/修正/排除决定、理由、执行日期和对应工作表范围。高里程超过 1,000,000 km 的排除属于有理由的暂定筛选，不是已证明录入错误；保留全样本比较。高价格 IQR 旗标只做诊断，不自动删除。

## 3. 分组与统计证据

在同一证据工作簿保留六个分析投影：`Full_all`、`Full_luxury`、`Full_nonluxury`、`Screen_all`、`Screen_luxury`、`Screen_nonluxury`。每个工作表只需六列：Original_Row、Brand_Clean、Segment、Car_Price、Registration_Age、Kms_Driven。通过 Excel 筛选后复制**可见单元格**、粘贴数值生成；数值内部精度必须保留。不要把隐藏行一起复制，不要再次通过 CSV。

全样本来自清洗后的全量原始数据；Screen 组按审计表里明确记录的筛选规则形成。不得把 5,000 行图形样本用于计算全样本统计。若存在 Unclassified 品牌，单独披露其数量，不能让 luxury + non-luxury 自动等于全样本而隐藏未知项。

在各工作表创建**工作表局部名称** Price、Age、Usage，分别指向 D、E、F 列实际数据区间，排除标题且不使用整列。每个表保持其实际尾行记录。然后在该工作表保留以下真正的 Excel 公式；对三个关键变量分别执行：

| 指标 | 价格公式示例 |
| --- | --- |
| 有效 n | `=COUNT(Price)` |
| 均值 | `=AVERAGE(Price)` |
| 中位数 | `=MEDIAN(Price)` |
| 众数 | `=IFNA(MODE.SNGL(Price),"No mode — all values unique")` |
| 样本标准差 | `=STDEV.S(Price)` |
| 最小、最大 | `=MIN(Price)`、`=MAX(Price)` |
| Q1、Q3 | `=QUARTILE.INC(Price,1)`、`=QUARTILE.INC(Price,3)` |
| IQR | `=QUARTILE.INC(Price,3)-QUARTILE.INC(Price,1)` |
| 年龄—价格 Pearson r | `=CORREL(Age,Price)`，须先确保范围中的记录一一对应且均有效 |
| 里程—价格 Pearson r | `=CORREL(Usage,Price)`，同样保留共同有效记录与成对 n |

如果某变量存在真正的多个众数，用 `MODE.MULT` 保留**实际众数值**；不能把“并列众数数量”填进众数栏。`IFNA` 只针对没有重复数值的有效数据区间；先检查有效 n，不能对空区间报告“all values unique”。本轮用户对原始 XLSM 的核对结果为：价格和里程均无重复值；报告应使用 `No mode — all values unique`，并保留 Excel 核验结果。

可再验证唯一性：在临时工作表把原始精度数值排序，用 `=IF(AND(ISNUMBER(D3),ISNUMBER(D2)),D3=D2,FALSE)` 比较相邻值，统计 TRUE 数量。若数值有效 n>0 且没有相邻重复，则没有众数。不要对百万行使用逐行 COUNTIF 全列的平方级重复检查；不要用显示格式判断是否相同。

结果保留公式而不是只存粘贴数值。在 Excel 中重新计算并保存，记录 Excel 版本、核验日期及每项统计的数据范围。各分组有效 n、行数及筛选数量应能对账；不依赖“看起来接近旧结果”。

## 4. 真正在 Excel 中重新抽取 5,000 行

1. 从已核验的 Screen_all 建立 `Sampling_pool`，保留六列和固定 Original_Row，记录候选行数。RAND 应覆盖每一条候选记录，不能只覆盖已选中的 5,000 行。
2. 新列 `Random_Key` 的第一条数据填 `=RAND()`，下填全部候选行。
3. **立即复制整个 Random_Key 数据区间，选择性粘贴→数值**；保存工作簿。检查这列已没有 RAND 公式，并记录冻结日期。RAND 没有可记录的固定 seed，冻结值和原始行号是本次抽样可复核的依据。
4. 选中**整张候选数据表**排序，第一关键字 Random_Key 升序，第二关键字 Original_Row 升序；不能只排序随机数列。
5. 将前 5,000 条记录的完整六列及固定 Random_Key 复制到 `Sample_5000`。候选不足 5,000 条时如实披露。保留抽样池、固定随机数、行号、筛选规则和抽取时间；不重复 RAND 来挑选更好看的图形。
6. 在 `Sampling_log` 记录候选 n、样本 n、样本豪华/非豪华 n、候选品牌分布及抽样文件版本。两张散点图共用同一份已冻结样本。

## 5. 在 Excel 中生成并保存图表

在 `Sample_5000` 用“插入→散点图（XY）”创建年龄—价格和里程—价格两图。x 轴分别是年龄（years）和里程（km），y 轴价格（INR）；豪华/非豪华分开系列。按 Segment 排序可使两个系列使用连续范围，但必须连同整行一起排序，保留随机数和 Original_Row。

如使用对数价格轴，只对图的显示轴设置；全量 CORREL 保持原始价格尺度。确认价格均为正数后再使用对数轴。图注记录真实候选 n、抽样 n、各组样本数、冻结 RAND 和保留行号的方法。不要保留旧 Python 图片作 Excel 生成的证据。

用 PivotTable 保存各年龄/组别的 n 与平均价格，制作年龄组均值图。按 Excel `PERCENTILE.INC` 形成使用量十分位边界，记录边界值和并列值分配规则，再保存各里程组/品牌组的 n、平均使用量与平均价格。等宽价格直方图明确组距、分母及任何未显示尾部的数量；所有价格统计仍保留未显示尾部。

保留真正的 Excel 图表对象及其数据范围，再复制进 Word。统计表、清洗计数、散点图和分组图须在最终 PDF 中呈现；读者不应依靠额外文件才看得懂主要结论。
