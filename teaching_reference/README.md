The Word version contains editable paragraphs and 13 native tables, with charts retained as images. References and automatic page numbering are included. It was rendered and checked as eight pages; pagination can vary with local fonts and Word settings.

The main report contains 1,000 words including section headings, excluding title/metadata, tables, figures/captions and references. The PDF includes the numerical summaries, graphical evidence, data-quality decisions, sources and rubric mapping. The Excel workbook has ten sheets documenting the analysis and a reproducible 5,000-row graphical sample. The original full dataset and course PDFs are not included in this folder.

The source CSV had 1,005,000 rows and 20 columns. The eight transferred slices were reconstructed and verified against the original SHA256. The source workbook screenshot confirmed randomisation. The primary cohort screens 6,151 observations exceeding 1,000,000 km; the full sample remains as a comparison. PDF page count, main-text completeness, numerical formula checks, cohort reconciliation, Excel error checks and visual layout inspection passed.

The assessment guide restricts students' own assessment use of AI to simple editing assistance. This document is for teaching reference.
