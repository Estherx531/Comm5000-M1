## 获取包含原始数据的完整 Excel

完整工作簿保留原始 `DATA`、`Dataset!B6` 和 VBA，并包括实际计算公式、固定统计结果、6,000 条随机候选、5,000 条图表样本及五个原生 Excel 图表。原始车辆数据不属于你已授权的 GitHub 上传范围，所以下载包用分析工作表与原始 XLSM 合并。

Mac 操作：

1. 下载并解压 `COMM5000_M1_Downloads.zip`，保留文件在同一文件夹。
2. 从你提供的同一 OneDrive 链接下载原始随机化 XLSM。
3. 打开“终端”，输入 `bash` 和一个空格，再把 `Assemble_Complete_Excel.command` 拖入终端，按回车。
4. 在弹出的窗口选择原始 XLSM。脚本核验四个原始部件并生成一个新文件，保存在“下载”文件夹，名称为 `COMM5000_M1_Complete_Analysis_日期时间.xlsm`。
5. 用 Microsoft Excel 打开新工作簿，等待公式与图表链接自动更新。

脚本只合并已完成的文件部件；统计、抽样与图表在云端已经通过 OfficeCLI 完成。它不执行 Python、统计计算或随机化宏，也不安装软件。原始 XLSM 保留。

文件选择后的 ZIP、SHA256 和合并流程已在云环境中使用真实源文件完成验证。macOS 文件选择窗口无法在 Linux 云环境中执行，未宣称对这个窗口完成实机测试。

## 本次修订依据

数值来源统一为原始 XLSM 的完整存储精度。价格和行驶里程在所有显示分组中均为 `No mode — all values unique`。年龄众数为实际年份值。

主要统计使用全部相应分组：原始 1,005,000 条，主分析保留 998,849 条；豪华车为 Audi、BMW、Mercedes（先 TRIM）。超过一百万公里的 6,151 条记录保留在全样本比较中。高价格保留，IQR 仅作额外诊断。

抽样使用原生 Excel `RAND()` 生成均匀候选行号及独立排序随机数，先固定随机数，再计算原始行号、首次出现规则和里程筛选。5,957 条候选唯一且符合筛选条件，排序后取 5,000 条：豪华车 1,194 条、非豪华车 3,806 条。两个散点图使用同一固定样本。价格坐标是工作簿实际计算的 `log10(price / INR 10,000)`；统计和相关性使用原始价格。

完整工作簿保留活跃源公式及原生计算结果快照。若修改原始数据或 Controls 中的筛选阈值，需要更新统计快照与抽样记录。本次 M1 不执行假设检验或预测模型。

OfficeCLI 是独立的 Office 文件编辑器与 Excel 公式引擎；计算由 OfficeCLI 1.0.155 自动执行，不宣称进行了人工 Microsoft Excel 界面操作。
